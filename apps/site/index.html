FAQ

Questions

Can I use my Claude Pro or ChatGPT Plus subscription?

No. Those subscriptions cover the chat apps only. 8Bit Agents needs an API key from a model provider, where you pay for what you use, or a free local model through Ollama or LM Studio.

What does a run cost?

You pay your model provider directly for what the agents use. The cost of the current run shows in the top bar, and the run stops when it reaches the limit you set. Local models cost nothing per run.

Can the agents mess up my computer?

They work inside one workspace folder and can't read or write files outside it. Shell commands wait for your approval, so read each one before you say yes.

Is my code sent anywhere?

Only to the model provider you set up, as part of the agents' prompts. With a local model, nothing leaves your computer. See the privacy page for details.

Why does my computer warn me when I install it?

Early builds aren't code-signed yet. On Windows, choose More info › Run anyway. On macOS, open the app once, then go to System Settings › Privacy & Security and choose Open Anyway. Signed builds are on the way.
