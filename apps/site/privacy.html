Privacy

Last updated 25 October 2026. In short: we don't collect anything about you.

The app

  • No account, no analytics. 8Bit Agents doesn't ask who you are and doesn't report what you do.
  • Your API keys stay on your computer, encrypted with your operating system's keychain. They're sent only to the model provider they belong to.
  • Your goals, files and the agents' work go to the model provider you chose (for example Anthropic or OpenAI), as part of the agents' prompts. That provider's own privacy policy covers what happens there. With a local model (Ollama, LM Studio), none of it leaves your computer.
  • Update checks: the app asks GitHub whether a newer version exists, and downloads it from GitHub if so. GitHub sees that request like any other web request.
  • Settings, run history and the agents' workspace are stored only on your computer.

This website

  • No cookies, no analytics, no trackers, no ads.
  • Fonts and images are served from this site, not from third parties.
  • The download section asks GitHub's public API for the latest release, so the buttons point at the right files.
  • The site is hosted on GitHub Pages. GitHub may keep standard server logs, such as IP addresses; see GitHub's privacy statement.
  • The demo office runs entirely in your browser. Nothing you click or answer in it is sent anywhere.
